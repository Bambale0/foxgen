## 2. Главный системный маршрут

`external event -> aiohttp route -> handler/router -> validation/auth -> database/service layer -> state transition -> user/operator response`

## 3. Telegram bot trace

### Главное меню

`Telegram update`
-> `bot/main.py` webhook handler
-> `Dispatcher.feed_update`
-> `AccessGuardMiddleware`
-> router in `bot/handlers/common.py`
-> keyboard from `bot/keyboards.py`
-> navigation callback or next FSM state

### Ограничители доступа

До выполнения бизнес-логики middleware проверяет:

- бан пользователя
- maintenance mode
- required channel subscription
- admin bypass only for admin management events

## 4. Generation trace

### Telegram image/video launch

`callback/message`
-> `bot/handlers/generation.py`
-> FSM state/data update
-> model/type/input validation
-> `check_can_afford` / related balance preconditions
-> `add_generation_task`
-> provider service call
-> save request snapshot / task metadata
-> async provider completion
-> webhook handler in `bot/main.py`
-> `complete_video_task` or failure path
-> result delivery to user

### Mini App generation launch

`POST /mini-app/api/generate-*`
-> `bot/miniapp.py`
-> `initData` validation
-> payload normalization
-> DB read/write + same provider services
-> task tracking in `generation_tasks`
-> client polls `task-detail` / bootstrap refresh

## 5. Payments trace

`user selects package`
-> `bot/handlers/payments.py` or Mini App payment endpoint
-> `create_transaction`
-> provider-specific session/invoice creation
-> external payment
-> webhook or poll/reconcile
-> provider signature/idempotency checks
-> `_complete_transaction`
-> `add_credits`
-> referral/partner side effects
-> UI refresh / notification

## 6. Feed / prompt / referral trace

`completed generation`
-> user chooses publish/share/remix/repeat
-> DB flags and social counters updated
-> feed/comment/like/remix tables used
-> deep link generated by `bot/miniapp_links.py`
-> link re-enters bot or Mini App
-> selected item/profile/feed route opens with scoped context

## 9. Failure points to watch

- webhook arrives without known task
- balance deducted but provider launch failed
- duplicate webhook/payment completion
- Mini App request without valid Telegram session
- old/legacy model alias diverges from canonical pricing key

Подробные карты вынесены в тематические `tracemap_*` файлы.
