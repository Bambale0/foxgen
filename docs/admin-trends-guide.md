# Инструкция администратора: раздел «Тренды»

Раздел **«Тренды»** — это публичная витрина готовых шаблонов для генерации изображений. Наполнять её может только администратор. Пользователи видят опубликованные примеры и могут запускать генерацию через кнопку **«Повторить шаблон»**.

## 1. Как открыть управление трендами

1. Откройте Telegram-бота под администраторским аккаунтом.
2. Нажмите **«Открыть Mini App»**.
3. В нижнем меню откройте вкладку **«Тренды»**. Она находится сразу после вкладки **«Студия»**.
4. В правой части заголовка должна отображаться кнопка **«Добавить»**.

Если кнопки **«Добавить»** нет, Mini App не распознал аккаунт как администратора. Закройте Mini App, снова откройте его из Telegram и убедитесь, что используете нужный Telegram-аккаунт.

## 2. Как добавить новый тренд

Во вкладке **«Тренды»** нажмите **«Добавить»**. Откроется форма **«Новый тренд»**.

### Название тренда

Короткое и понятное название, которое объясняет результат.

Примеры:

- «Новогодняя фотосессия»
- «Фото в стиле делового журнала»
- «Кукольный 3D-портрет»
- «Образ в русском народном стиле»

Максимальная длина — 80 символов.

### Короткое описание

Объясните пользователю, что получится и какое исходное фото лучше загрузить.

Пример:

> Загрузите портрет по пояс. Шаблон сохранит лицо и превратит фото в зимнюю журнальную съёмку.

Максимальная длина — 240 символов.

### Нейросеть

Выберите модель, для которой подготовлен шаблон.

Важно:

- если шаблон должен работать по фотографии пользователя, выбирайте модель, поддерживающую референсы;
- не выбирайте модель только потому, что она новая — сначала проверьте результат именно на этом prompt;
- после публикации выбранная модель будет автоматически подставляться пользователю.

### Preview шаблона

Нажмите **«Загрузить изображение»** и выберите пример результата.

Поддерживаемые форматы:

- JPEG;
- PNG;
- WEBP.

Рекомендации к preview:

- используйте готовый результат, полученный с тем же prompt и выбранной моделью;
- лучше всего подходит квадратное изображение 1:1, так как карточка отображается квадратной;
- не добавляйте мелкий текст по краям — он может обрезаться;
- изображение должно сразу показывать, какой результат получит пользователь;
- используйте только материалы, на которые у вас есть права.

Чтобы заменить загруженное preview, нажмите крестик на изображении и загрузите новое.

### Скрытый prompt

Вставьте готовый рабочий prompt, который будет использоваться при повторе шаблона.

Prompt не показывается в карточке тренда. После нажатия пользователем **«Повторить шаблон»** он автоматически подставляется в форму генерации вместе с выбранной моделью.

Хороший шаблонный prompt должен:

- описывать ожидаемый результат без привязки к конкретному человеку;
- сохранять лицо и ключевые особенности пользователя, если это требуется сценарием;
- чётко описывать одежду, фон, свет, ракурс, композицию и стиль;
- не содержать имён, ссылок и случайных деталей из тестовой генерации;
- работать с разными исходными фотографиями, а не только с одним примером;
- соответствовать правилам допустимого контента.

Пример структуры:

```text
Используй загруженное фото человека как основной референс.
Сохрани узнаваемые черты лица, возраст и естественные пропорции.
Создай профессиональный портрет в зимней студии: мягкий кинематографичный свет,
снежный фон, тёплая одежда, реалистичная кожа, высокая детализация.
Не изменяй пол и основные черты внешности. Без текста и водяных знаков.
```

## 3. Публикация

Перед публикацией проверьте, что заполнены обязательные поля:

- название;
- нейросеть;
- preview;
- скрытый prompt.

Описание можно оставить пустым, но лучше всегда объяснять пользователю, какое фото загрузить.

Нажмите **«Опубликовать тренд»**. После успешной публикации карточка сразу появится в начале раздела.

Дополнительная модерация не требуется: тренд, созданный администратором, публикуется сразу.

## 4. Как проверить тренд после публикации

Не считайте тренд готовым, пока не проверили полный пользовательский сценарий.

1. Найдите новую карточку во вкладке **«Тренды»**.
2. Нажмите **«Повторить шаблон»**.
3. Убедитесь, что открылась вкладка создания фото.
4. Проверьте, что выбрана нужная нейросеть.
5. Проверьте, что prompt подставился полностью.
6. Добавьте подходящий референс, если он требуется модели.
7. Запустите одну тестовую генерацию.
8. Проверьте, что результат соответствует preview и описанию.

Также желательно открыть Mini App с обычного пользовательского аккаунта и проверить:

- кнопка **«Добавить»** отсутствует;
- тренд отображается;
- кнопка **«Повторить шаблон»** работает;
- пользователь не может удалить тренд.

## 5. Как удалить тренд

В карточке тренда администратор видит кнопку с иконкой корзины.

1. Найдите нужную карточку.
2. Нажмите кнопку удаления.
3. Дождитесь, пока карточка исчезнет из списка.

Тренд деактивируется и перестаёт показываться пользователям. Запись не удаляется физически из базы данных, поэтому историю можно сохранить для технического разбора.

Удалить тренд также можно в текстовом Telegram-боте: откройте **«🔥 Тренды»**, найдите карточку и нажмите **«🗑 Убрать тренд»**.

## 6. Раздел «Тренды» в текстовом боте

Открыть витрину можно:

- кнопкой **«🔥 Тренды»** в главном меню;
- командой `/trends`.

Тренды отображаются по одному в виде карусели. Кнопки со стрелками переключают шаблоны.

Пользователь видит кнопку **«🔥 Повторить шаблон»**, которая открывает Mini App с выбранным шаблоном.

Команда `/prompts` оставлена как технический совместимый алиас для старых сообщений и ссылок, но основной пользовательский раздел называется **«Тренды»**.

## 7. Частые проблемы

### Нет кнопки «Добавить»

Причины:

- Mini App открыт не с администраторского Telegram-аккаунта;
- Mini App был открыт до обновления и использует старую сессию;
- сервер или frontend ещё не обновлён.

Что сделать:

1. Полностью закройте Mini App.
2. Вернитесь в чат с ботом.
3. Снова нажмите **«Открыть Mini App»**.
4. Проверьте аккаунт Telegram.

### Не загружается preview

Проверьте формат файла. Используйте JPEG, PNG или WEBP. Попробуйте сохранить изображение заново и повторить загрузку.

### Кнопка публикации нажимается, но тренд не создаётся

Проверьте обязательные поля: название, preview, модель и prompt. Сообщение об ошибке появится над каталогом.

### Тренд создан, но его не видно

Закройте и заново откройте вкладку **«Тренды»** или перезапустите Mini App. Если карточка всё равно не появилась, проверьте серверные логи Mini App.

### Повтор шаблона не запускается

Проверьте:

- доступна ли выбранная модель;
- нужен ли модели обязательный референс;
- хватает ли пользователю бананов;
- не нарушает ли prompt правила контента;
- работает ли загрузка исходного изображения.

## 8. Чек-лист перед публикацией

- [ ] Название понятно без дополнительных объяснений.
- [ ] Описание говорит, какое фото нужно загрузить.
- [ ] Preview сделано тем же шаблоном и той же моделью.
- [ ] Выбрана подходящая нейросеть.
- [ ] Prompt не содержит данных тестового пользователя.
- [ ] Prompt работает минимум на двух разных фотографиях.
- [ ] Лицо и важные детали сохраняются корректно.
- [ ] Выполнена тестовая генерация через кнопку **«Повторить шаблон»**.
- [ ] Тренд проверен с обычного пользовательского аккаунта.

## Краткая схема

```text
Mini App → Тренды → Добавить
→ название
→ описание
→ нейросеть
→ preview
→ скрытый prompt
→ Опубликовать тренд
→ Повторить шаблон
→ тестовая генерация
```

## 9. Видео-тренды

Администратор может публиковать не только изображения, но и готовые видео-шаблоны.

### Через Mini App

1. Откройте **«Тренды» → «Добавить»**.
2. Выберите **«Видео-тренд»**.
3. Заполните название и описание.
4. Выберите видео-нейросеть.
5. Загрузите ролик-пример в MP4, WEBM или MOV.
6. Добавьте скрытый prompt.
7. Нажмите **«Опубликовать тренд»**.
8. Проверьте кнопку **«Повторить видео»**.

После повторения пользователь попадёт во вкладку **«Видео»**. Нейросеть и prompt будут подставлены автоматически.

### Через текстовый бот

1. Откройте **«🔥 Тренды»**.
2. Нажмите **«🎬 Загрузить видео-тренд»**.
3. Пройдите мастер: название → описание → видео-модель → ролик → prompt.
4. Проверьте карточку и нажмите **«✅ Опубликовать видео-тренд»**.

Видео-пример в текстовом боте принимается как обычное видео или как файл MP4, WEBM либо MOV размером до 20 МБ.

Фото- и видео-тренды находятся в одной публичной витрине. Создавать и удалять их может только администратор.
