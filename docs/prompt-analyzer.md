# Единый анализатор промптов

Раздел главного меню «Промпт по фото» работает как единая точка создания промпта без дополнительных кнопок.

Поддерживаемый ввод:

- текстовое описание или черновые мысли;
- фотография;
- фотография с текстовой подписью;
- голосовое сообщение;
- голосовое сообщение, затем фотография.

Результат содержит только две версии готового промпта:

- русскую;
- английскую.

Negative prompt, рекомендация модели, расшифровка голоса и Gemini Omni prompt в этом сценарии не запрашиваются и пользователю не выводятся.
